# Meu Laço

App pra laçador escolher um laço de cabeça, pé ou individual — pelo nome ou por três perguntas (prova, giro, mão).

Marcas e fotos são de mentira. O pedido também: nome, cidade, e pronto.

## Como rodar

```bash
npm install
npm run dev
```

Abre em [http://localhost:4317](http://localhost:4317).

## O que tem

- **Já sei o laço** — busca na prateleira (10 laços)
- **Me ajuda a escolher** — prova, giro do peão, gosto na mão, referência opcional
- Ficha com maciez, giro, comprimento, grossura, 4 tentos, sintética
- Pedido de um laço só

## Stack

Next.js, TypeScript, Tailwind, shadcn/ui.
